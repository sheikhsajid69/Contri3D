# Security Policy

## Supported Versions

We actively support and provide security updates for the latest major release of Contri3D.

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

We take the security of Contri3D very seriously. If you discover a security vulnerability within this project, please follow these guidelines:

1. **Do not open a public GitHub issue.** Reporting vulnerabilities publicly can put existing users at risk before a patch is available.
2. **Report via GitHub Private Vulnerability Reporting:** Go to the repository's [Security tab](https://github.com/sheikhsajid69/Contri3D/security/advisories) and click **Report a vulnerability**, or reach out directly to the maintainer (`sheikhsajid69`) via GitHub profile contact information.
3. **Include details:** Please provide detailed steps to reproduce the vulnerability, potential impact, and any mitigation ideas if you have them.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to release a patched version as quickly as possible. Thank you for helping keep Contri3D and our developer community safe!
